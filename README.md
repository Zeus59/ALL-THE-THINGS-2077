
# ALL-THE-THINGS-2077

A modular Lua project for Cyberpunk 2077 modding.

## Overview
This repository contains scripts and data structures to extend and customize Cyberpunk 2077. The modules are organized into categories such as clothes, cyberware, vehicles, weapons, and more.

## Directory Structure
- `data/` – Data for clothes, cyberware, mods, quickhacks, vehicles, weapons, etc.
- `profil/` – Profile and attribute files.
- `settings/` – Settings, changelog, update information.
- `system/` – UI modules and system functions for the various categories.
- `trad/` – Translations and interface descriptions.
- `init.lua` – Initialization script.
- `settings.json` – Configuration file.

## Installation
1. Clone the repository:
   ```powershell
   git clone https://github.com/The-Destructor95/ALL-THE-THINGS-2077.git
   ```
2. Copy the files into your Cyberpunk 2077 mod directory.
3. Adjust the settings in `settings.json` and the Lua files as needed.

## Usage
- Modules can be used individually or in combination.
- Edit the data in the Lua files to suit your needs.
- For UI customization, edit the files in the `system/` directory.
